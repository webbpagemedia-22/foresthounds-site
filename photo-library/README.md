# Photo library

Photos for the weekly blog posts. The Sunday blog agent picks the best fit
for each story from here, and only creates an AI image when nothing fits.

## Adding photos

1. Click **Add file → Upload files** at the top of this folder on GitHub.
2. Drag your photos in and click **Commit changes**.

That's it. You don't need to resize them or write descriptions.

## Before you upload: remove the location

This repository is public, so anything uploaded here can be seen by anyone,
and it stays in the history even if deleted later. Photos taken at home or
on a regular route can show where you live in their location data.

- **iPhone:** select the photos, tap Share → Options → turn off Location,
  then save or send them to your Mac.
- **Mac Photos:** File → Export → tick "Remove location information".

## photos.json

The list of photos with their descriptions, alt text and tags, which the
blog agent reads. It will be filled in automatically for new uploads.

Files in this folder are not served on foresthounds.co.uk. Only photos
picked for a post are copied into the site's images folder.
